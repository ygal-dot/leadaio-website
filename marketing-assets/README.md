# Marketing assets (public)

Public copies of LeadAIO brand images, so emails and other sites can load them. Named per the naming guide in the private `Leadaio-project` repo (`marketing-assets/README.md`).

Emails load these from:
`https://raw.githubusercontent.com/ygal-dot/leadaio-website/email-assets/marketing-assets/brand/<file>`

LeadAIO brand files only. The AI platform icons are in `email-assets/`.

| File | Use |
|---|---|
| `brand/logo-leadaio-color-560w.png` | Standard logo, light backgrounds |
| `brand/logo-leadaio-white-360w.png` | Logo for dark backgrounds |

Don't rename, move or delete these files: sent emails load them by their exact names.
