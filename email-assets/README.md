# Email assets

Images used in LeadAIO emails. This folder is public so email apps can load them.

| File | Use |
|---|---|
| `icon-chatgpt-96w.png`, `icon-claude-96w.png`, `icon-grok-96w.png`, `icon-perplexity-96w.png`, `icon-gemini-96w.png` | AI platform icons in the "Built for visibility on" box |

Emails load them from:
`https://raw.githubusercontent.com/ygal-dot/leadaio-website/email-assets/email-assets/<file>`

The LeadAIO logos are in `marketing-assets/brand/`.

The files with the older names (`chatgpt.png`, `leadaio-logo.png` and so on) are kept so emails already sent still show their images. Don't rename or delete any file here.
