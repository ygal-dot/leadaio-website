# Email assets

Images used in LeadAIO emails. This folder is public so email apps can load them.

| File | Use |
|---|---|
| `icon-chatgpt-96w.png`, `icon-claude-96w.png`, `icon-grok-96w.png`, `icon-perplexity-96w.png`, `icon-gemini-96w.png` | AI platform icons on white tiles (so they show in dark mode), used in the "Built for visibility on" box |

Emails load them from:
`https://raw.githubusercontent.com/ygal-dot/leadaio-website/email-assets/email-assets/<file>`

The LeadAIO logos are in `marketing-assets/brand/`.

Don't rename, move or delete these files: sent emails load them by their exact names.
